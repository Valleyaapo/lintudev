## 2026-02-15 - Prefetching in Astro Static Sites
**Learning:** For Astro static sites (`output: 'static'`), enabling prefetching via `prefetch: true` in config and using `data-astro-prefetch` on specific links significantly improves perceived navigation speed without complex router setup.
**Action:** Always enable prefetching for critical user journeys (like project details) in static portfolio sites to enhance UX.
