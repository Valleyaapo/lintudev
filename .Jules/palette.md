## 2024-03-14 - Accessible Form Associations and Submit Feedback
**Learning:** In interactive React components like `Contact.tsx`, implicitly wrapped labels or standalone labels without `htmlFor` fail to properly associate with inputs for screen readers. Explicitly linking labels using `htmlFor` matching the input's `id` ensures accessibility and allows clicking the label to focus the input. Additionally, providing explicit asynchronous feedback by setting `aria-busy="true"` and an SVG spinner inside the submit button prevents user confusion and double submissions during API calls.
**Action:** Always verify that input fields have explicit `id` attributes and that labels map to them using `htmlFor`. When handling asynchronous submissions, buttons should disable, show visual indication (like spinners with `flex items-center gap-2`), and set `aria-busy="true"` while maintaining color contrast.
