## 2024-05-14 - Improve Contact Form Accessibility and Async State UX
**Learning:** For interactive UI forms, using `aria-busy` and a visual loading spinner explicitly informs screen readers and visual users about asynchronous ongoing operations like form submission, preventing user frustration. Also, explicitly tying `label` to their `input` via `id` and `htmlFor` improves screen reader compatibility. Finally, honeypot fields explicitly meant for trapping spam bots should be completely hidden from both visual display and screen readers using `aria-hidden="true"`, ensuring accessibility features don't misinterpret them.
**Action:** When designing forms with asynchronous submissions, always ensure buttons receive `aria-busy` and appropriate visual loading indicators when disabled during `submitting` states. Ensure `id` and `htmlFor` are used strictly for explicit label associations. Always add `aria-hidden="true"` to honeypot fields.
