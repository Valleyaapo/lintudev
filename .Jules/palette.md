## 2025-02-18 - [Accessibility in Forms]
**Learning:** Adding `id` and `htmlFor` attributes is crucial for linking labels to inputs, ensuring screen readers announce the label when the input is focused. Also, `aria-busy` on submit buttons provides essential feedback for screen reader users during async operations.
**Action:** Always verify form inputs have associated labels and use `aria-busy` for loading states to improve accessibility and user feedback.
