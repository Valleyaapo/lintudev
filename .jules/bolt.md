## 2024-03-02 - Optimize Request Handler by Moving Regular Expressions to Module Scope
**Learning:** Moving Regular Expression declarations from inside request handlers (like API routes) to the module scope improves performance by avoiding repeated `RegExp` object allocation and garbage collection overhead on every request. However, it's critical to ensure these regular expressions do not use the global (`g`) flag, as that maintains internal state (such as `lastIndex`) across multiple requests, which can lead to hard-to-debug bugs.
**Action:** When working with API routes or frequently called functions, always identify static regular expressions and extract them to module scope. When extracting, explicitly check and omit the global (`g`) flag unless specifically required and state is manually managed.
